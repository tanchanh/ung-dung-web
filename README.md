# 🌌 Danh Mục Ứng Dụng Web An Toàn

Trang Hub trung tâm hiển thị, tìm kiếm và phân loại các công cụ ứng dụng web đơn lẻ. Nơi quản lý toàn bộ hệ sinh thái ứng dụng tiện ích hoạt động độc lập, bảo mật và chạy hoàn toàn ở phía client.

---

## ✨ Tính Năng Nổi Bật

* **Bộ lọc thông minh:** Hỗ trợ phân loại dự án nhanh chóng theo danh mục (**Tất cả**, **Tiện ích**, **Sức khoẻ**, **Dữ liệu**...).
* **Tìm kiếm thời gian thực:** Định vị nhanh ứng dụng cần dùng ngay khi đang gõ ký tự vào ô tìm kiếm.
* **Giao diện hiện đại:** Thiết kế tối màu kết hợp hiệu ứng chuyển sắc đổ bóng bóng bẩy, bo góc tinh tế, hiển thị tối ưu trên cả máy tính lẫn điện thoại.
* **Tải file cục bộ:** Cho phép tải nhanh mã nguồn ứng dụng về máy để lưu trữ và sử dụng hoàn toàn **offline**.

---

## 🛠️ Hướng Dẫn Sử Dụng

* **Tìm kiếm:** Gõ từ khoá tên ứng dụng hoặc mô tả vào thanh tìm kiếm ở đầu trang. Bấm nút dấu **X** nếu muốn xoá nhanh từ khoá để tìm lại từ đầu.
* **Lọc danh mục:** Nhấp vào các thẻ danh mục tương ứng để thu hẹp phạm vi hiển thị nhóm công cụ mong muốn.
* **Truy cập ứng dụng:** Nhấp thẳng vào thẻ tiêu đề của ứng dụng bất kỳ để mở trang chạy trực tuyến trên GitHub Pages.
* **Lưu trữ ngoại tuyến:** Nhấp vào nút **Tải File Cục Bộ** ở góc dưới mỗi thẻ ứng dụng để tải file HTML tương ứng về máy tính hoặc điện thoại.

---

## 📝 Thông Tin Phát Triển

* **Tác giả:** Dương Tấn Chánh
* **Mã nguồn:** HTML5, CSS3 (Biến CSS kết hợp Flexbox/Grid nâng cao), JavaScript Thuần (Vanilla JS)
